# Drawing drafts

This supplementary package holds the drawing files of the figures in the
manuscript "Less a Weak Source than a Different One: Vulnerability, Similarity and Direction in CNN-ViT Adversarial Transfer under an Architecture-by-Initialization Design". The schematic figures (Figures 1 to 6) were drawn in
Microsoft Visio as vector drawings, shape by shape on a 0.25 mm grid, and every
shape was read back from Visio by a millimetre controller before the figure was
exported. Each .vsdx file below is the drawing of the printed figure named beside
it. The data figures (Figures 7 to 17) were built with matplotlib in millimetre
card layouts; for each of them the figure manifest (.fig.json: venue, size,
panels, colours and data sources) and the layout controller report (.mm.json) are
given. The files are the drafts as drawn; nothing was edited for this package.
Figure 1 embeds the first four test images of CIFAR-10 and of CIFAR-100 on its
data-set cards, enlarged by pixel repetition; no image in any figure was generated
or edited.
