% FOY:M10.1:1789,1793,1794,1796
The three CIFAR-10 training pairs of the original cell and their evaluations ran on an NVIDIA RTX 5060 Ti (16~GB). The CIFAR-100, SVHN and $L_2$ campaigns, the selection trajectories, the external pool and all registered blocks ran on an RTX 5090 (32~GB). Code ran in a container built on NVIDIA's PyTorch~25.01 image (PyTorch 2.6.0a0, CUDA 12.8) with timm 1.0.27, NumPy 1.26.4 and RobustBench commit \texttt{78fcc9e}, under deterministic cuDNN settings and seed 42. The registered CIFAR-100, ImageNetV2 and gradient blocks reused existing checkpoints and trained no new model. They ran from a committed snapshot of the rebuilt container, with a forked copy of the transfer-matrix script that reproduced the original outputs exactly in a regression run.

% FOY:M9.7:1673
% KAYNAK: eski metin 04:638 (C1 AutoAttack: tam test kumesi, tohumlu 1000'lik parcalar)
AutoAttack used the standard configuration (APGD-CE, APGD-T, FAB-T, Square), on the full test set in seeded 1{,}000-image chunks for the original pair and on the first 1{,}000 test images for the six new models.

The three-seed training pipeline of the original pair took 21.7 GPU-hours. The six new runs took 17.79 hours for their clean and adversarial phases (block B3 in Figure~\ref{fig:prereg_chain}), on a GPU at times shared with another process. Adversarial training stopped early in every run, after 36 to 58 epochs, with selected epochs between 16 and 38.
